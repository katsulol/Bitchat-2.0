## 2. Protocol & Storage Changes Summary

   - Added optional `invitation: Option<GatewayPairingInvitation>` to `ControlFrame::IdentityBind` with canonical signature domain `b"bitchat2-gateway-invite-v1"`.
2. **Wrapped DEK Envelope Format ([`core/src/storage/key.rs`](file:///C:/Users/pulki/OneDrive/Pictures/Desktop/Bitchat/core/src/storage/key.rs), [`AndroidKeystoreProvider.kt`](file:///C:/Users/pulki/OneDrive/Pictures/Desktop/Bitchat/app/android/app/src/main/kotlin/com/bitchat/bitchat2/AndroidKeystoreProvider.kt))**:
   - Versioned binary layout: `[magic: "BC2K" (4B)] || [version: 1 (1B)] || [key_version: u32 BE (4B)] || [iv_len: u8 (1B)] || [iv (12B)] || [ciphertext_and_tag]`.
3. **SQLite Outbox AAD Binding ([`core/src/storage/sqlite.rs`](file:///C:/Users/pulki/OneDrive/Pictures/Desktop/Bitchat/core/src/storage/sqlite.rs))**:
   - Extended `construct_aad` from 87 bytes to 103 bytes by appending `created_at_ms: u64 BE` and `expires_at_ms: u64 BE`.
4. **Trust & Voucher SQLite Tables ([`core/src/trust/store.rs`](file:///C:/Users/pulki/OneDrive/Pictures/Desktop/Bitchat/core/src/trust/store.rs))**:
   - Added `peer_trust` and `capability_vouchers` tables in `TrustStore`.
5. **Capability Voucher Canonical Signing ([`core/src/trust/voucher.rs`](file:///C:/Users/pulki/OneDrive/Pictures/Desktop/Bitchat/core/src/trust/voucher.rs))**:
